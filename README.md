# Asansör Düğmesinin İkinci Basılış Davası

**Resmi kurum:** Katlar Arası Yargı ve Bekleme İdaresi (KAYBİ)  
**Dosya no:** ZEMIN-2026/02  
**Ciddiyet seviyesi:** Yüzde 412. Asansör bunu kaldıramaz ama dava kaldırır.

Bu depo, bir kez basılmış asansör düğmesinin, aynı kata ikinci kez basılmasını *non bis in idem* sayarak açtığı davayı yürüten yazılımdır. Yazılım çalışır. Asansör gelmez. Bu bir özelliktir.

## Neden var

Çünkü birinci basış yeterlidir. İkinci basış, düğmeye hakarettir. Üçüncü basış ise artık kabahatten suça terfidir. Yazılım bunu bilimsel değil, inatla hesaplar.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Asansör firmasıyla anlaşma da yoktur.

```bash
python3 dava.py --kat 7 --bas 3 --tanik kapi
python3 dava.py --demo
```
